# 幽玄 Web

幽玄是一个蓝调清新风格的在线音乐页面，适合放松、阅读和安静聆听原声吉他音乐。

![幽玄 Web 页面](docs/screenshot.png)

## 浏览

打开部署网址即可浏览。点击歌曲列表右侧的播放按钮，底部播放器会加载对应 MP3；页面支持手机和电脑浏览器。

本地预览可以直接打开 `index.html`，或在当前目录启动任意静态文件服务器。

## 内容

- 推荐歌单和氛围标签
- 五首原声吉他纯音乐
- 固定底部播放器
- 作者、来源与 Creative Commons 授权说明
